## Featured Projects

### [VAD_Training](https://github.com/seanxgao/VAD_Training)
Frame-level VAD distillation pipeline on large-scale Mandarin speech:
- 10 ms frame-level labels distilled from a large “teacher” model  
- Student model with \<10 ms latency, ONNX export, JSON/NumPy outputs  
- >99% frame agreement vs teacher on eval segments

### [EDGE](https://github.com/seanxgao/EDGE)
Graph-based long-term memory layer for LLM applications:
- Hybrid FAISS IVF-PQ + graph retrieval
- Ranking with XGBoost-style models
- Designed for low-latency, multi-modal recall

### [SCOPE](https://github.com/seanxgao/SCOPE)
Spectral clustering toolkit:
- CPU/GPU fallback with PyTorch / NumPy
- Hierarchical spectral bisection & graph kernels
- Focus on practical performance and clean APIs
